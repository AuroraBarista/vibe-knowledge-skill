# 画风

## 系列气质

- 没有旁白。画面上的大字和一行字幕负责讲，图形是主角。
- 画面一直在动，镜头连续（一镜到底）：段落之间用推、拉、平移、穿过连接，不硬切。
- 一个镜头只讲一个意思，留大片空白；主体少，关系清楚。
- **物体讲道理**：点是人，粒子流是车，线是关系，水位是比例。数字由模型实际算出来，画面跟着模型状态走，不手调。
- 时长约 2 分钟。已做的 4 期在 104–124 秒之间。

## 默认画风：黑金细线

| 用途 | 颜色 |
|---|---|
| 背景（近黑，偏暖） | `#050404` / `#0b0a08` / `#17130d` |
| 主文字（象牙白） | `#eee7da` |
| 金（强调、线、光点） | `#e6c88c`，亮金 `#f3e1b6`，暗金 `#8a6a3c` |
| 弱化文字 | `#9a9284` |
| 唯一的警示色（拥堵、错误） | `#e0644c`，少量使用 |

- 线：细的发丝线，金色或象牙白，透明度有层次。
- 粒子和尘埃：暖金，有视差，可以带 bokeh 景深。
- 后期：轻 bloom（三维场景）、四角压暗、细颗粒（约 0.025）。辉光不能糊掉文字。

## 字体

- 中文：思源宋体（Noto Serif SC）。大标题用 Light（250），正文和字幕用 Medium（500），封面用 Bold（700）。
- 数字和英文：EB Garamond，正体和斜体。
- 若自己的工程提供 `scripts/fonts.py`，它可按 `index.html` 里实际用到的字裁剪字体。改了文字以后要重新跑。

| 元素 | 规格（1920×1080） |
|---|---|
| 片名 | Light 150px，字距 .24em，下面配一行 EB Garamond 斜体英文名 |
| 开头大字 | 上行 Medium 58–64px；下行 Light 约 172px；关键数字 EB Garamond 约 250px 金色 |
| 段落大字 | Medium 46px 起；数字 EB Garamond 110–150px |
| 字幕 | Medium 46px，`top: 930–936px`，居中，字距 .06em，深色多层 text-shadow |
| 章节标签（需要时） | 年份 EB Garamond 112px + 地名 Medium 42px，左上角 |

- 字幕区下方垫一层很淡的渐变（底部约 34% 黑），画面再亮也能看清字幕。
- 结尾大字压在复杂画面上时，背后加一块柔和的径向暗区。

## 换画风

题目本身有强烈的视觉身份时可以换画风。例如梵高那期用油画笔触，Mondrian 题材可以用色块。换画风时，字体、文字规则和“一镜到底”保持不变。换之前先做一个 10 秒以内的小样给本人看，除非本人说了直接做。

## 禁止

- 外部链接、二维码、仓库路径、本机用户名路径。
- 水印、参考文献、“示意”小字、免责声明、小号英文说明。
- 真实品牌 logo，除非这一期就在讲它。
- 把商业音乐混进文件。
