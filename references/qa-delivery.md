# 检查与交付

## 每轮修改后

用 `snapshot` 抽帧看 contact sheet，结果放在 `film/qa/<轮次>/`。
- 第一轮看整片 12–16 帧。
- 之后只看改过的时间点，再加上前后的转场。
- 开头单独看 0.3、0.9、1.5、2.3、3.0、4.0 秒。

## 渲染前清单

- [ ] **开头**：0 秒就在动；0–2 秒有共情或矛盾，2–5 秒有转折；用了大字；约 8 秒内进入正文。
- [ ] **文字**：每一条都能看清，包括压在亮的或花的画面上的；不和标签、图形重叠；没有两行字幕同时出现。
- [ ] **事实**：PLAN 核对表覆盖了画面上的每个数字、日期和引语；拿不准的已经改成稳妥说法。
- [ ] **禁止项**：没有外部链接、二维码、路径、水印、参考文献、“示意”小字、小号英文。
- [ ] **画面**：没有过曝的大块、黑洞、穿帮（世界边缘、物体内部、近景大方块）；转场连续。
- [ ] **lint**：0 error。
- [ ] 改过文字以后，字体重新裁剪过（`deliver.py` 会自动做）。

## 交付

1. 在后台运行 `deliver.py <film 目录> --name "<标题>"`。它会依次做这些事：
   - 构建（有 `build.mjs` 或 `net.mjs` 时）；
   - 裁剪字体，跑 lint；
   - 有配乐生成器时生成临时配乐，母带到 −14 LUFS；否则可用自备 WAV；
   - 以 60fps 渲染；
   - 转码上传版（CRF 20，无音轨）；
   - 混音生成预览版；
   - 检查两个文件的时长、音轨和响度；
   - 删掉原始渲染文件。
   - 加 `--archive-old v1`：把旧成片改名成 `<标题>-v1-…` 保留下来，再出新版。
2. 用 `frame_sheet.py` 从**上传版成片**里抽帧，检查最终文件，不能只看 snapshot。
3. 写 `film/README.md`（模板：`templates/README-film.md`），写清楚：成片文件、怎么做的、怎么重新生成、QA 记录。
4. 在自己的作品目录记录文件、事实来源和 QA 结果。
5. 保留旧版本，遵循当前工作区的协作规则。
6. 把预览版、上传版和抽帧图发给本人。汇报这些内容：
   - 开头怎么设计的；
   - 一句话说清全片结构；
   - 验证了什么；
   - 没验证什么，通常是没试听配乐；
   - 已知不够好的地方，写出具体时间点。

## 封面（可选）

- 规格：3:4，1086×1448。标题是两行粗宋体（象牙白 + 香槟金），下面一个能代表这期主题的物件或画面。黑金风格，继承本期成片的画风。
- 素材从这一期的 `film/exports/` 取帧，封面放在 `videos/<期>/cover/`，最终提示词写进 README。
- 生成封面要用图像生成工具（Codex 里有 imagegen）。当前环境没有这个工具时，就把文案和画面方案写好，交给 Codex 做。
