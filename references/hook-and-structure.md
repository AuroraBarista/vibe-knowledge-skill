# 选题、开头与结构

## 选题标准

一个好题目要同时满足四点：
1. **反直觉**：一句话就能说出矛盾，比如“每一组都赢，合起来却输”。
2. **能画出来**：机制可以变成点、线、粒子、网络、水位或者一个世界。
3. **数据可靠**：有经典研究或可以复算的例子，每个数字都能找到出处。
4. **看完能带走**：一个判断方法，或者一种新的看法。

再加两点：和生活有关（通勤、朋友圈、找工作、等车、花钱）；开头能“演”出来，不能只靠讲。

- 推荐排序是编辑判断，不是流量预测，要说明这一点。

## 开头（最重要）

本人两次强调：开头要“抓人眼球”，要“让人共情，尤其 2 秒和 5 秒”；还要“紧凑、沉浸、用大字”。

- **0 秒就在动**：一开场就在最有代表性的画面里运动，比如飞行、滑动、俯冲，不要从静止的空画面开始。梵高那期从星空漩涡里飞出来。
- **0–2 秒：共情或矛盾**。让观众看到“你”或者一个具体处境：导航上的“还要 65 分钟”、深夜朋友圈里你的“♡ 3”。
- **2–5 秒：转折**。把个人处境放大成所有人的问题（“可是，所有人的导航，都这么说”），或者抛出反转。
- **开头的文字用大字**：不要只用底部字幕。分成上下两行，上行是铺垫小字，下行是大字，逐字落下（带 blur 和 scale，每个字间隔 0.05 秒）。关键数字用金色 EB Garamond 放大。
- **约 8 秒内进入正文**：片名可以压在转场上（比如倒带、拉远），不要单独占 3 秒以上。
- 开头背后的画面太花时，在文字后面加一块柔和的暗区。

## 结构

常用结构：冷开场 → 片名 → 历史锚点或真实案例 → 机制动画 → 反直觉转折 → 落到生活 → 一句收尾。

- 按 126 BPM 排：1 小节 = 1.905 秒，段落、数字跳动、翻卡都落在小节线上。开头约 4–6 小节，正文每段 4–10 小节，全片 55–65 小节（约 105–124 秒）。
- 每段只讲一件事，用一句字幕说清楚。字幕约 2.5–4.5 秒一条，不要一屏放两行字幕。
- 收尾一句话，最好回到开头的那个“你”或那幅画面（例：“数据没有骗你，是‘合起来’骗了你”）。

## 写字幕

- 中文为主，句子短，一句一个意思，用直接的动词。
- 数字尽量用具体值，并在 PLAN 的核对表里写出算式或出处。
- 引语只用有出处的原话，例如梵高写给提奥的信。拿不准就不加引号，改成转述。
