# 四种视觉结构（方法参考）
原始工作流用于辛普森悖论、布雷斯悖论、友谊悖论和梵高题材。完整工程、成片、个人反馈与账号数据不在此仓库内。

| 题材 | 视觉结构 | 可复用方法 |
|---|---|---|
| 辛普森悖论 | 2D HTML / SVG 点阵 | 同一批点先分组再合并，数字由数据计算 |
| 布雷斯悖论 | Three.js 线框城市、车流粒子 | 从一个通勤者出发，把个人选择放大成系统结果 |
| 友谊悖论 | 3D 关系网 | 先展示个人处境，再拉远显示网络；布局离线计算 |
| 梵高 | TypeScript + Three.js 笔触世界 | 连续镜头串联地点与年代，GPU point sprites 表现笔触 |

这些是设计方向，不是随仓库提供的模板引擎，也不是流量保证。历史、数字和引语需为每期重新核对。
